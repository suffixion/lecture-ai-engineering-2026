# 第1回 宿題：基礎

## 実施内容
質問「LoRAとは何ですか？」を、gemini-3.5-flash-liteとgemini-3.1-flash-liteで各3回実行した。AIE_MODELでモデルを切り替え、uv run python -m app.askを使用した。temperatureは明示指定しなかった。

## 比較結果
- 3.5：比喩が「小さなノート」「おまけのパーツ」「付け焼き刃（付箋）」と変化した。回答中の容量の例も、1回目の「数MB〜数百MB」から3回目の「数MB〜数十MB」に変わった。
- 3.1：1・2回目は同文だった。3回目では「破滅的忘却」の項目がなくなり、複数LoRAの同時利用の説明が加わった。
- モデル間：元の重みを固定して小さな部分を学習するという説明は共通した。3.5では身近な比喩が用いられ、3.1の1・2回目では2つの行列の掛け算についての説明も含まれた。

## 実行中の問題と対応
当初の比較対象gemini-3.8-flashは503エラーで回答を取得できなかったため、gemini-3.1-flash-liteへ変更した。このエラーは比較した6件の回答に含めていない。
