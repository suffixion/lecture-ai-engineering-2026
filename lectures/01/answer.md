## 宿題

- 取り組んだレベル：基礎
- やったこと：「LoRAとは何ですか？」を、`gemini-3.5-flash-lite` と `gemini-3.1-flash-lite` で各3回実行した。`AIE_MODEL` でモデルを切り替え、`uv run python -m app.ask` を使用した。temperatureは明示指定しなかった。当初の比較対象 `gemini-3.8-flash` は503で回答を取得できなかったため、3.1に変更した。
- 結果：
  - 3.5では比喩が「小さなノート」「おまけのパーツ」「付け焼き刃（付箋）」と変化した。回答中の容量の例も、1回目の「数MB〜数百MB」から3回目の「数MB〜数十MB」に変わった。
  - 3.1では1・2回目が同文だった。3回目では「破滅的忘却」の項目がなくなり、複数LoRAの同時利用の説明が加わった。
  - 両モデルとも元の重みを固定して小さな部分を学習するという説明は共通した。3.1の1・2回目には、3.5では見られなかった2つの行列の掛け算の説明も含まれた。
